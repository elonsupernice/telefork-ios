# TaleFork

TaleFork 是一款从零设计的 iPhone 互动分支故事应用。用户不是被动观看视频，而是在每个关键场景作出选择，形成自己的故事路线、结局图谱与收藏档案。

## 产品身份

- 产品名称：TaleFork
- 中文描述：每个选择，都会长出新的故事
- Bundle Identifier：`com.talefork.storypaths`
- 平台：iPhone
- 最低系统：iOS 17.0
- 当前版本：1.0.0
- 当前构建：1
- 开发方式：Swift 6、SwiftUI、纯本地数据

## 独立性边界

本工程采用独立的产品定位、品牌、交互模型、数据结构、视觉语言和测试体系。TaleFork 是纯本地互动阅读应用，不包含视频播放、剧集列表、会员或登录功能。

## 当前功能

- 三个原创互动故事，每个故事包含多条路线和多个结局
- 场景阅读、选择推进、路线回退与重新开始
- 自动保存当前进度和已解锁结局
- 路线图谱与结局收集
- 句子收藏与故事档案
- 首次启动偏好设置
- 深色/浅色外观、动态字体和减少动画适配
- 繁体中文、英文、日文界面
- 本地隐私政策和使用条款
- 不联网、不追踪、不含广告与第三方 SDK

## 构建

使用 Xcode 打开 `TaleFork.xcodeproj`，选择任意 iPhone 模拟器运行。当前工程不绑定任何开发者 Team；新 Apple 开发者账号到位前只进行模拟器构建和测试。
