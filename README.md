# TaleFork

TaleFork 是一款从零设计的 iPhone 竖屏互动短剧应用。用户观看原创短剧，在关键场景作出选择，进入不同剧集与结局，并在路线图中回看自己的故事路径。

## 产品身份

- 产品名称：TaleFork
- 产品标语：每次选择，都通往另一幕
- Bundle Identifier：`com.talefork.storypaths`
- 平台：iPhone
- 最低系统：iOS 17.0
- 当前版本：1.0.0（Build 1）
- 技术：Swift 6、SwiftUI、AVKit、纯本地持久化

## 上线内容

- 完整原创互动短剧《雨停之前》
- 6 段本地竖屏视频、4 个互动节点、2 个可收集结局
- 《静默频率》《借来的明天》两部独立预告卡片
- 繁体中文、英文、日文界面与剧集文案

## 完整功能

- 首次启动引导
- 剧场首页、分类筛选、剧名搜索、短剧详情
- 竖屏播放器、播放/暂停、拖动进度、自动连播、退出续播
- 剧集选择、剧情分支、结局解锁、重看与重新开始
- 路线图、已看节点和结局收集
- 收藏短剧、观看足迹和进度管理
- 外观、触感、减少动画、自动连播设置
- 本地隐私政策、使用条款和一键清空数据
- 小屏/大屏、深色/浅色、Dynamic Type 与安全区适配

## 数据与商业模式

当前版本无需登录、无需联网、完全免费，不含会员、内购、广告、分析 SDK 或第三方支付。观看进度、收藏、足迹、结局和设置仅保存在设备本地。

## 独立发布边界

本工程不复用任何既有产品的名称、包名、签名、账号、支付代码、服务地址或品牌素材。工程未绑定任何 Apple Developer Team；正式签名与 App Store Connect 记录必须由新的独立开发者账号创建。

## 构建

使用 Xcode 打开 `TaleFork.xcodeproj`，选择任意 iPhone 模拟器运行。项目生成脚本位于 `Scripts/generate_project.py`；媒体与数据完整性校验位于 `Scripts/validate_drama.swift`。
